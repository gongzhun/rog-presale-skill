## 执行步骤

### 第一步：获取官方产品列表（含中英文名称）

首先用 WebSearch 搜索 ASUS/ROG 官方发布的 20周年产品列表，目标是获取每款产品的**中文名**和**英文名**对照：

- `ROG 20th anniversary product lineup 2026 site:asus.com`
- `ROG 20周年纪念版 全系产品 中文名`

整理出一份"产品中英文对照表"，例如：

| ROG Gladius IV 20th Anniversary | ROG 魂刃 IV 20周年纪念版 |
| ... | ... |

如果官方未公布中文名，则以英文名为准，中文名标注"待确认"。

### 第二步：搜索各平台预售信息

**中文平台（京东、天猫、苏宁）使用中文产品名搜索**，国际平台使用英文名：

| 天猫 Tmall | 对每款产品用中文名搜索：`{产品中文名} 预售 site:tmall.com`；通用兜底：`ROG 20周年 预售 site:tmall.com 2026` |

- 结果中如有第三方店铺条目，标注"非自营，已过滤"并不计入统计

**若参数包含 `--tmall-official`，天猫搜索改为仅限旗舰店：**

- `ROG 20周年纪念版 {产品中文名} 预售 京东` / `ROG 20th anniversary presale Amazon 2026`

**每条搜索结果中，必须尝试提取直接商品页 URL**（jd.com/item/xxx、detail.tmall.com/item/xxx、amazon.com/dp/xxx 等格式）。若搜索结果中可见完整链接，直接记录；若仅有搜索结果列表页，则记录列表页 URL 并在备注中注明"商品直链待确认"。

### 第三步：提取结构化数据

对每条搜索结果，尝试提取以下字段（无法确认的字段填写"待确认"）：

- **产品英文名**
- **产品中文名**（官方中文名；若无则填"待确认"）
- **产品类型**（主板 / 显卡 / 外设 / 笔记本 / 显示器 / 其他）
- **预售价格 / 参考售价**
- **预售开始日期**
- **发货 / 上市日期**
- **上架状态**，使用以下四个值之一：
  - `已上架` — 商品页已存在，可下单或预售
  - `价格已确认/未上架` — 官方已公布售价，但电商页面尚未上线
  - `即将开始` — 官方已预告但未公布价格也未上架
  - `已售罄` / `在售`
- **店铺类型**（京东自营 / 京东第三方 / 天猫旗舰店 / 天猫第三方 / 苏宁自营 / Amazon官方 / ASUS官网 / 其他）
- **购买/预售链接**：优先记录直接商品页 URL；若搜索结果仅含列表页则记录列表页并注明"直链待确认"；确实无任何链接则填"待确认"
- **备注**（限量版、套装、赠品等关键信息）

## 参数说明

如果用户在调用时传入了参数（`$ARGUMENTS`），按以下规则处理：

- 传入平台名（如 `jd` / `tmall` / `amazon`）：只搜索指定平台
- 传入产品类型（如 `主板` / `显卡` / `外设`）：在搜索关键词中追加该类型
- 传入完整路径（如 `~/Documents/ROG/report.md`）：保存到指定目录和文件名，跳过所有询问直接生成
- 传入目录路径（如 `~/Documents/ROG`）：询问是否生成后，直接保存到该目录，无需再次询问目录
- 传入文件名（如 `report.md`）：使用该名称保存，询问生成后再询问保存目录
- 传入 `--cn`：只搜索中文平台（京东、天猫、苏宁）
- 传入 `--global`：只搜索国际平台（Amazon、ASUS官方）
- 传入 `--jd-official`：京东搜索范围限定为**京东自营**，过滤第三方店铺；可与 `jd` 参数组合，也可单独使用（此时默认仍搜索全平台，只是京东结果只含自营）
- 传入 `--tmall-official`：天猫搜索范围限定为**华硕/ROG 官方旗舰店**（asus.tmall.com），过滤非旗舰店结果；可与 `tmall` 参数组合使用

用户传入的参数：$ARGUMENTS
