整理出一份"产品中英文对照表"，例如：

### 第三步：提取结构化数据

- **产品中文名**（官方中文名；若无则填"待确认"）
- **产品类型**（主板 / 显卡 / 外设 / 笔记本 / 显示器 / 其他）

- **发货 / 上市日期**
- **库存状态**（预售中 / 即将开始 / 已售罄 / 在售）
- **平台链接**
- **备注**（限量版、套装、赠品等关键信息）

## 参数说明

如果用户在调用时传入了参数（`$ARGUMENTS`），按以下规则处理：

- 传入平台名（如 `jd` / `tmall` / `amazon`）：只搜索指定平台
- 传入产品类型（如 `主板` / `显卡` / `外设`）：在搜索关键词中追加该类型
- 传入完整路径（如 `~/Documents/ROG/report.md`）：保存到指定目录和文件名，跳过所有询问直接生成
- 传入目录路径（如 `~/Documents/ROG`）：询问是否生成后，直接保存到该目录，无需再次询问目录
- 传入文件名（如 `report.md`）：使用该名称保存，询问生成后再询问保存目录
- 传入 `--cn`：只搜索中文平台（京东、天猫、苏宁）
- 传入 `--global`：只搜索国际平台（Amazon、ASUS官方）
